# i18n Katkı Rehberi (#225)

Tarodan'daki **tüm kullanıcıya görünen metinler** tek paylaşılan katalogdan gelir:
`packages/i18n/src/catalog/tr.json` + `en.json`. Web, admin, mobil ve API aynı
kataloğu tüketir. Hardcoded kullanıcı metni eklemek yasaktır — lint ve CI
gate'leri bunu yakalar.

## Yeni metin ekleme akışı

1. **Anahtarı iki kataloğa da ekle** — `tr.json` ve `en.json` anahtar setleri
   birebir aynı olmak zorundadır (CI: `check-catalog.mjs`).
   - Türkçe kaynak metindir; İngilizce doğal, profesyonel çeviri olmalıdır.
   - Dinamik değerler ICU biçimindedir: `"{count} aktif ilanınız var"`.
     Çoğul/seçim gerekiyorsa ICU plural/select kullanın.
2. **Codegen'i çalıştır:** `pnpm --filter @tarodan/i18n codegen`
   (`src/generated/keys.ts` MessageKey union'ını günceller; bayat kalırsa CI
   kırmızı). Paketi tüketen app'te typecheck için `pnpm --filter @tarodan/i18n build`.
3. **Tüket:**
   - **web / admin (next-intl):** `const t = useTranslations();` +
     `t("admin.users.title")` (tam yol, namespace argümanı yok). Server
     component'te `getTranslations`. Statik obje/kolon katalogları hook
     çağıramaz → `t`-parametreli builder fonksiyon deseni
     (`type T = ReturnType<typeof useTranslations<never>>`). zod şemaları →
     `schema(t)` factory. Dinamik anahtar lookup'larında `as const` ile
     literal tipleri koruyun.
   - **mobil (i18next + ICU):** `useTranslation` + aynı anahtarlar.
   - **API (NestJS):** exception'lar için
     `throw new NotFoundException(i18nMessage('server.order.notFound', { orderNumber }))`
     — `AllExceptionsFilter` mesajı isteğin dilinde render eder (yanıtta
     `i18nKey` de döner). Controller success mesajları:
     `I18nService` + `@ReqLocale() locale` + `this.i18n.translate(...)`.
     E-posta/bildirim gibi request'siz kanallar alıcının
     `User.preferredLanguage` tercihiyle render edilir.

## Anahtar adlandırma

- `common.*` — platformlar arası genel etiketler (önce burada ara, varsa
  YENİDEN KULLAN; yeni genel etiketse buraya ekle).
- `<domain>.*` — web+mobil ortak vitrin alanları; `mobile.*` mobil-özel.
- `admin.<bölüm>.*` — admin dashboard'ı (`admin.operations.orders.title`).
- `server.<domain>.*` — API'nin ürettiği mesajlar (exception/response);
  `server.notification.*` bildirim şablonları; `email.*` e-posta şablonları.

## Lint guardrail: `@tarodan/no-hardcoded-turkish`

`packages/eslint-plugin` içindeki kural, Türkçe karakter içeren string
literal / template / JSX metnini işaretler (İngilizce, URL, class adı vb.
yanlış-pozitif üretmez).

- **admin:** `error` — migrate edilmemiş dilimler (finance, marketing,
  messaging, reviews, seller-*, system/logs, test-tools) `.eslintrc.json`
  override'ında kapalıdır; o dilimler migrate edilirken listeden çıkarın.
- **web:** `warn` — kalan statik/yasal içerik temizlendikçe `error`'a
  çekilecek. Veri dosyaları (il/ilçe listesi, marka verisi) kalıcı istisna.
- Katalog dışında kalması MEŞRU metin (backend-data eşleme desenleri,
  endonim "Türkçe", intl-context'siz kod yolları, developer-facing hatalar)
  için satır bazlı `// eslint-disable-next-line @tarodan/no-hardcoded-turkish -- <gerekçe>`
  kullanın — gerekçesiz disable PR review'da reddedilir.

## CI gate'leri

- `packages/i18n` `typecheck` script'i `check-catalog.mjs` çalıştırır:
  (1) tr/en anahtar paritesi, (2) `keys.ts` güncelliği. İkisi de kırmızıda
  merge'i bloklar.
- Lint job'ı `no-hardcoded-turkish` kuralını uygular (admin'de error).
- API unit testleri jest'te kataloğu kaynak koddan tüketir; katalog JSON'ları
  jest'te `apps/api/test/jest-json-default-transform.js` ile sarılır
  (esModuleInterop kapalı — detay için o dosyanın yorumuna bakın).

## Sık hatalar

- Tek kataloğa anahtar ekleyip diğerini unutmak → parity gate kırmızı.
- Codegen'i çalıştırmamak → "generated MessageKey union up to date" hatası.
- `t`'yi modül-düzeyi sabitin içinde çağırmak → React hook kuralı ihlali;
  builder desenini kullanın.
- Türkçe metni "geçici" hardcode etmek → lint error; anahtar eklemek
  toplamda daha hızlı.
