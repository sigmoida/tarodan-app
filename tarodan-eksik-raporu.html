Atlanan 249 test — neden çalıştırılmadı?

Bunlar "hata" değil; API testi kapsamı dışında oldukları için bilinçli atlandı. Her birinin kodda gerekçesi yazılı.

  • 84Saf arayüz (web + mobil). Buton, boş ekran, yükleme animasyonu, URL yönlendirmesi gibi tarayıcı/uygulama görünümü testleri — bunların API tarafı yok, o yüzden backend testinde çalıştırılamaz.
  • 141Test ortamı taklit (stub) kullanıyor. Gerçek dosya depolama (S3), gerçek e-fatura (eLogo), gerçek kargo firması ve AI görsel denetimi test ortamında taklit/kapalı. Bu servislerin gerçek davranışını test edenler atlandı (ör. resim yükleme varyantları, uygunsuz görsel engeli, S3 erişilemezlik hatası).
  • 18Test altyapısı sınırı. Uygulama testte tek süreçte çalışıyor; bir servisi kapatıp yeniden başlatma gerektiren testler (ör. Arama motorunu durdurup yedek arama devreye giriyor mu) yapılamıyor.
  • 6Zaman/cron bağımlı. Belirli bir sürenin geçmesini bekleyen (zamanlanmış görev) testleri.
